# Wiki Springfield

Wiki Springfield es un sitio web estático que presenta contenido sobre los personajes de la serie animada Los Simpson. El proyecto busca ofrecer una experiencia de consulta sencilla y visualmente coherente, ideal para proyectos educativos, demostraciones de frontend y prácticas de maquetado.

La aplicación está construida con HTML, CSS y Bootstrap 5, y cuenta con una página principal y páginas internas dedicadas a personajes emblemáticos como Homero Simpson y la familia Simpson. El diseño es responsive y prioriza una navegación clara y una presentación limpia de la información.

## Características

- Navegación responsive con menú desplegable
- Páginas de personajes con estructura clara y contenido organizado
- Efectos visuales: contenedores con sombras coloridas y bordes redondeados
- Estilo consistente con paleta inspirada en Los Simpson
- Arquitectura estática sin dependencias adicionales

## Estructura del repositorio

- `index.html` — Página principal del sitio
- `pages/homero.html` — Página dedicada a Homero Simpson
- `pages/familiasimpson.html` — Página dedicada a la familia Simpson
- `css/bootstrap.min.css` — Archivos de Bootstrap
- `css/styles.css` — Estilos personalizados del proyecto
- `img/` — Imágenes utilizadas en el sitio

## Instalación

1. Clona el repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
```

2. Abre `index.html` en tu navegador.

> No es necesario instalar dependencias adicionales, ya que el sitio funciona como una aplicación web estática.

## Uso

- Usa el menú de navegación para alternar entre las páginas principales y de personajes.
- Explora la ficha de Homero Simpson y revisa las frases más famosas con presentación visual.
- Ajusta el estilo en `css/styles.css` si deseas personalizar colores, tipografías o efectos.
